# VahanaSec Support

## Before Asking for Help

Please review the README, project documentation, existing issues, and current implementation status.

VahanaSec is an evolving project. Some features may be planned rather than implemented.

## Bug Reports

Open an issue with:

- The affected version or commit.
- Operating system and relevant environment details.
- Steps to reproduce the problem.
- Expected and actual behaviour.
- Relevant error messages with sensitive information removed.

Provide a minimal reproducible example where possible.

## Feature Requests

Explain the problem, intended use, proposed solution, alternatives, and relevant security or safety considerations.

## Questions

Use GitHub Discussions if enabled, or open an appropriate non-sensitive issue in the repository.

Do not place credentials, personal information, proprietary vehicle data, or vulnerability details in public discussions.

## Security Issues

Do not report exploitable vulnerabilities publicly. Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Response Expectations

VahanaSec is a community-driven project. Responses and implementation timelines depend on maintainer availability. No fixed response time or support service is guaranteed.

Use all tools only in simulated or explicitly authorised environments.

Thank you for supporting responsible automotive security research.
